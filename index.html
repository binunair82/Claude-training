Self-contained demo builds — no frameworks, no build step, no dependencies.

UOB IT PMO — Project Board Live demo

A Kanban board in a single HTML file: drag-and-drop with a keyboard-accessible fallback, filtering, overdue highlighting and inline delete confirmation.

The board holds no data between visits — there is no localStorage, no database and no back end, so a refresh deliberately restores the seeded tasks. That is intended behaviour for a training demo, not a bug.
